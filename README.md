## 🚀 Overview

This website is built with a focus on:

* Clean UI/UX
* Performance
* Recruiter-friendly structure
* Real-world impact presentation

It highlights projects, experience, and technical capabilities in a structured and visually engaging way.

---

## ✨ Features

* 🎯 Minimal & modern design
* ⚡ Smooth animations and transitions
* 📊 Impact-driven project showcase
* 🧠 Skills and tech stack visualization
* 📬 Functional contact form (Formspree integration)
* 📱 Fully responsive across devices
* 🌌 Interactive hero section with dynamic elements

---

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Styling:** Custom CSS (modern UI, animations)
* **Libraries/Concepts:**

  * Intersection Observer (scroll animations)
  * Typing animation
* **Deployment:** GitHub Pages
* **Forms:** Formspree
